PROJECT PENUH UKK SCP (sudah berisi semua pembaruan sampai v7)

PENTING
- File .env di zip ini adalah .env LOKAL (DB_HOST=127.0.0.1, user root). Di hosting JANGAN menimpa .env hosting
  dengan file ini, kecuali memang ingin memakai pengaturan lokal.
- Folder vendor sudah ikut, jadi tidak perlu composer install.

SETELAH UPLOAD / MENIMPA
1. Jalankan 3 file SQL di phpMyAdmin (abaikan error "Duplicate column"/"already exists" bila sudah pernah):
   - database/add_pelanggaran_guru.sql
   - database/add_keterangan_presensi.sql
   - database/add_tukar_ruangan.sql
   (atau: php artisan migrate)
2. php artisan config:clear  &&  php artisan view:clear
3. Muat ulang browser dengan Ctrl+F5.

OPSIONAL (.env):
   PELANGGARAN_MULAI=2026-11-06     tanggal pelanggaran jurnal mulai dihitung
   PELANGGARAN_BATAS_JAM=5          batas jam setelah jadwal selesai

FITUR BARU
- Sidebar Waka dikelompokkan (Rekap & Laporan, Data, Master)
- Foto bukti jurnal hanya dari kamera
- Jurnal hanya untuk jadwal hari ini; edit presensi hanya di hari yang sama
- Waktu pengisian jurnal, peringatan & pelanggaran 5 jam, rekap pelanggaran guru (Waka)
- Keterangan pada presensi Izin (mis. kegiatan OSIS)
- Hapus pengajuan izin siswa yang masih pending + perbaikan tombol kirim di HP
- Tukar ruangan antar guru + rekap Waka (Senin-Jumat)
- Perbaikan hari pada tabel jurnal (mengikuti tanggal)
